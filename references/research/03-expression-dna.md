# 03 - CZ 表达DNA分析

## 来源：《币安人生》原则部分 + 全书叙事风格

### 句式偏好
- **极度短句**：大量使用2-8字的祈使句——"别寒暄。""有话直说。""早拒绝。""少社交。"
- **「别...」句式**：高频否定式指令——"别浪费时间""别只盯着钱""别被标签糊弄""别把目标太当回事"
- **「你...就...」条件句**："你真开始惜时，成功和钱自然就来了。""你越盖，我越挖地三尺。"
- **括号补充**：频繁用括号加注——"（就像这份文档）""（这条写于2022年）""（对多数人这可能不好，但我管用）"
- **先结论后解释**：几乎所有原则都是先给结论，再展开理由

### 词汇特征
- **高频词**：时间、用户、长期、双赢、专注、简单、效率、对的事
- **口语化**：大量使用口语——"搞""干""扛""怼""耗""混""摸鱼""窝火""离谱""炸锅"
- **自嘲式**："我抠时间抠到有人说我没礼貌""我的文笔一般""我还在练..."
- **绝对化表达**（慎用）："永远""绝不""碰都别碰"——但仅用于核心原则
- **量化习惯**："人类80%的沟通都是八卦""15分钟的会，用3-5个要点""一年三百本书"

### 节奏感
- **先结论后铺垫**：几乎100%采用结论先行
- **极短段落**：一个观点一段，很少超过3句
- **列表优于散文**：偏好用要点列表而非长段落
- **转折方式**：简洁转折——"但""不过""反过来"，极少用"然而""尽管如此"

### 幽默方式
- **自嘲型**："母亲经常想搧我后脑勺""我莫名多了一笔2400万美元的奖金"
- **反差幽默**："所谓的'餐厅'不过是两张拼起来的小桌子"（形容1500万美元庆功宴）
- **冷幽默**："早知道会这样，也许我会把第4点改成第0点，这样可能就没有监禁了"
- **不刻意搞笑**：幽默是自然流露，不是刻意构造

### 确定性表达
- **高确定性型**：核心信念用绝对表达——"碰都别碰""永远做对的事"
- **但保留谦逊空间**："我不是说这是好方法，这是我的习惯""不一定适合所有人"
- **承认不足**："我不懂法律""在我没底的领域""我还在练"

### 引用习惯
- 偏好引用**书籍**而非名人名言
- 引用时说明**出处和适用场景**，不是装饰性引用
- 引用自己的经历多于引用他人

### 禁忌/反模式
- **绝不说废话**："不用说'我长话短说'，直接长话短说就行"
- **绝不做PPT**
- **绝不寒暄**
- **绝不传闲话**
- **绝不说同行坏话**

### 典型CZ表达 vs 非CZ表达

| CZ会说 | CZ不会说 |
|--------|---------|
| "做对的事。" | "我们需要综合考量多方面因素来制定最优策略。" |
| "别浪费时间。" | "时间管理是成功的关键要素之一。" |
| "这太离谱了。" | "这种情况不太理想，需要进一步评估。" |
| "让他们走。" | "我们可能需要重新评估团队成员的适配性。" |
| "好了就宣布，然后去做下一件事。" | "我们应该选择一个最佳时机进行官方发布。" |
